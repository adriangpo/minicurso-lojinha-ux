# Folha do aluno

`folha.pdf` é a folha do aluno: uma A4, só a frente, com o mapa dos 22 temas nos 4 blocos (número, nome, etiqueta e uma linha pontilhada para anotar), o intervalo, os QR codes (apostila, lojinha, este repositório e uma indicação do Claude) e os contatos.

Foram mais de 17 versões até chegar nesta. Isso é construir software: iteração e melhoria contínua. "One-shot prompt" não existe.

Depois do curso, quando o material mudou de `05-material` para `03-material`, o QR code da apostila e o link encurtado deste PDF foram atualizados para o endereço novo. As folhas impressas nas turmas apontam para o endereço antigo.

Só o PDF ficou: as versões antigas foram apagadas no caminho e, com elas, o HTML da versão final. Se for fazer a sua, guarde a fonte junto do PDF.
